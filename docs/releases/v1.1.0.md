## Compact manager and restart control

Installation starts Battery Tooltip immediately, enables sign-in startup by default, and adds one **Battery Tooltip** Start menu entry.

That entry opens a small management window: running status and version, an automatic-startup checkbox, and Start/Restart, Stop, Uninstall, and Close buttons. The window uses a 308-pixel logical width, 8-pixel margins, and 4-pixel button spacing. English and Simplified Chinese follow the mod's language setting.

- Start and restart from one button. Restart waits for the old module to unload before loading it again.
- Preserve automatic-startup preferences when restarting or stopping from the manager.
- Run operations in the background so the window stays responsive.
- Close the window without stopping the background tooltip. Escape and the title-bar close button do the same.
- Add a transparent battery-and-tooltip application icon, with nine Windows icon sizes from 16 to 256 pixels. Use it in the manager and its Start menu entry.
- Uninstall stops the module and removes the current installation's startup and Start menu shortcut; unrelated entries are preserved.
- Retain `Manage.cmd`, `Restart.cmd`, `Status.cmd`, and `Uninstall.cmd` for direct access and automation.
- Add regression checks for the single manager shortcut, quoted paths, ownership, and removal.
- Preserve child-process exit codes so successful operations are not incorrectly reported as failures; verify both successful and failed operations and their log output.
- Keep manager and startup logs under the installation directory's `artifacts` folder.

Download **BatteryTooltip-1.1.0.zip** and run **Install.cmd**. No Python is required for the release package. The original Windows battery icon and compact tooltip are preserved. Validated hardware compatibility remains Windows 11 25H2 x64, build 26200.9457; full reboot and hibernate cycles have not been reproduced as part of this release.
