## First release

Battery Tooltip adds compact battery telemetry to the existing Windows 11 battery icon's hover tooltip.

- Shows external power or battery power separately from the battery's charging/discharging state.
- Displays net charging/discharging power and estimated remaining time. Discharging while plugged in is supported.
- Supports English and Simplified Chinese, follows Windows by default, and allows an explicit language override.
- Preserves the original icon, taskbar percentage, and click behavior.
- Includes portable setup, startup, sample previews, and rollback scripts. The trial creates no startup entry and installs no additional hardware-reading driver.

### Downloads

- **battery-tooltip.wh.cpp**: create a custom mod in Windhawk, paste this source, and compile it. Disable the mod in Windhawk to restore the native tooltip.
- **BatteryTooltip-0.2.0.zip**: project source, scripts, tests, and a precompiled mod. Follow README.md; portable setup requires Python 3 and downloads the verified Windhawk runtime.
- **SHA256SUMS.txt**: checksums for the two downloads above.

### Validation and limits

The release workflow runs 22 checks covering both languages, language selection, unknown telemetry, time formatting, and battery discharge while external power is connected, then compiles and packages the mod.

Initial on-device validation used Windows 11 25H2 build 26200.9457, x64. The native tooltip and Chinese sample layout were confirmed by the user. Other Windows builds and real charging/discharging transitions have not yet been validated on hardware. This release remains experimental.

Power readings describe the battery, not whole-computer consumption. Remaining time is an estimate, especially while charging slows near full. Data refreshes when the tooltip opens. Windows updates may require compatibility changes.
