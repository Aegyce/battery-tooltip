## Confirmed updates with automatic download cleanup

Add a **Check updates** button beside automatic startup in the compact manager.

- Check the latest stable release from `Aegyce/battery-tooltip` when clicked. Compare installed and released versions numerically and reject downgrades and prereleases.
- Show the current and available versions and ask before downloading or installing. The confirmation defaults to No; cancellation downloads nothing.
- Verify the release download addresses, ZIP SHA256, extracted paths, package version, and precompiled checksums before modifying the installation.
- Install from an independent temporary helper so the management window can close and its files can be replaced, then reopen it.
- Preserve language, preview mode, charge target, startup preference, and running/stopped state. Restore the previous files and mod configuration if installation fails.
- Automatically remove the downloaded ZIP, extraction, temporary worker, and temporary snapshot after completion. Clean interrupted inactive jobs at the next check. Keep update logs in `artifacts/update.log`; retain a separate recovery backup only if automatic recovery itself fails.
- Add regression checks for version selection, download validation, installation, rollback, preserved preferences, and guarded cleanup.

Existing 1.1.0 users need to install **BatteryTooltip-1.2.0.zip** once to get the update button. Later versions can be installed from the manager after confirmation. Python is not required for release-package installation.

The original Windows battery icon and compact two-line tooltip are preserved. Validated hardware compatibility remains Windows 11 25H2 x64, build 26200.9457.
