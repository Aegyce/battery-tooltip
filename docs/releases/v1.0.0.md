## First stable release

Battery Tooltip now includes a complete installation and daily-use workflow for its native Windows 11 battery tooltip.

- Add `Install.cmd` with a precompiled mod and its runtime dependencies. Release-package installation no longer requires Python. The official Windhawk runtime is downloaded and verified during setup.
- Start automatically when the current user signs in. Startup can be disabled independently or omitted with `Install.cmd -NoAutoStart`.
- Verify that the native tooltip hook is ready before reporting a successful start. Add `Status.cmd` and a startup failure log.
- Handle Explorer initialization before its taskbar and `SystemTray.dll` are ready, including deferred symbol hooking.
- Remove the current installation's startup entry during rollback, verify DLL unloading, and retain saved native tooltip restoration.
- Verify precompiled-file checksums and preserve existing language, preview, and charge-target settings during package upgrades.
- Extend GitHub Actions with installation/startup regression checks and complete package generation.

The existing battery icon, compact two-line display, English/Simplified Chinese, live telemetry, charge/discharge estimates, and atomic configuration recovery remain available.

Validated Windows compatibility remains Windows 11 25H2 x64, build 26200.9457. Reboot/login and sleep/hibernate cycles require hardware verification; this release does not claim those cycles have been reproduced by automated tests.

Download **BatteryTooltip-1.0.0.zip**, extract it to a permanent directory, and run **Install.cmd**. Existing Windhawk users can use **battery-tooltip.wh.cpp** directly and manage startup through their Windhawk installation. SHA256 checksums are included.
