## Configuration persistence fix

Fixes a configuration-writing failure that could leave an empty INI and unload the battery tooltip mod, causing the native Windows tooltip to reappear even while Windhawk remained running.

- Stage complete configuration files and replace them atomically instead of truncating the original before writing.
- Preserve the original on file-lock errors and reject empty or incomplete configuration data.
- Keep the previous valid configuration in a `.bak` file and recover it when the current file is damaged.
- Use the same safe writer for startup, rollback, language, previews, builds, and portable runtime settings.
- Add configuration regression checks covering real reader locks, invalid input, cleanup, and recovery from a zero-byte file.

English/Simplified Chinese, live battery telemetry, estimated remaining time, and rollback remain available. No additional hardware-reading driver is needed.

Download **battery-tooltip.wh.cpp** for an existing Windhawk installation, or **BatteryTooltip-0.2.1.zip** for the portable setup and fixed scripts. Portable users affected by this bug should update the scripts; updating only the mod source does not fix the old configuration writer. SHA256 checksums are included.
